# EarnFlow

Premium rewards platform landing page — discover legitimate offers, complete tasks, and earn rewards.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Landing page uses mock/demo data only.
- Dark mode is the default; toggle lives in the navbar.
- Components are structured for easy backend integration later.
